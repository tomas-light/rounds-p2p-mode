# ROUNDS P2P Prototype 0.2.3

Сетевой прототип для публичной Steam-версии ROUNDS на Windows: лобби и приглашения через Steam, сервер на ПК одного игрока и штатная игровая синхронизация. Требуется только загрузчик BepInEx; RoundsWithFriends, UnboundLib и DuctTape не нужны.

Это локальный тестовый пакет, а не опубликованный релиз Thunderstore. Подключение через Steam не требует ручного ввода IP и настройки роутера. Steam может использовать прямой маршрут или ретранслятор Valve; название P2P не гарантирует прямое соединение.

## Установка

Оба игрока устанавливают одинаковую версию пакета в отдельный профиль **Rounds P2P Prototype** с BepInExPack_ROUNDS 5.4.1901. Импортируйте ZIP функцией **Import local mod** в настройках профиля r2modman или используйте `scripts/install-profile.ps1` из репозитория. Скрипт отказывается смешивать пакет с другими игровыми модами. Иконка входит в пакет; установщик сохраняет её в кеш менеджера.

Другу нужно передать сам ZIP и инструкции. Код экспорта профиля r2modman пока не считается подтверждённым способом переноса неопубликованных DLL. Перед обновлением закройте игровые процессы, использующие профиль.

## Подключение

1. Оба игрока запускают Steam и профиль через r2modman. Перед принятием приглашения у друга уже должна быть запущена игра с этим профилем.
2. Хост выбирает **Онлайн → Создать лобби**.
3. После готовности лобби хост выбирает **Пригласить друга**. Откроется интерфейс приглашений Steam.
4. Друг принимает приглашение Steam и подключается к лобби. Для игрового трафика используется канал Steam к серверу хоста; вводить адреса и порты не требуется.

Для кнопки приглашения нужен доступный игре оверлей Steam. Если он недоступен, мод показывает соответствующее сообщение и не меняет настройки Steam.

Звук игры сохраняется. F8 остаётся дополнительной диагностикой старого подключения по IPv4 и не требуется для сценария со Steam.

## Проверки и ограничения

Локальные проверки охватывают SDK Steam через `CreateSocketPair` и передачу реальных сообщений Photon. Такая проверка подтверждает работу отдельных сетевых компонентов, но не заменяет матч двух Steam-аккаунтов на разных компьютерах через интернет. Полная проверка приглашения и WAN-соединения двух игроков ещё требуется.

Обычная сборка запускает модульные, Photon-сетевые и установочные проверки. Команда `scripts/build.ps1 -SteamTests` дополнительно запускает тесты реального SDK Steam; для них нужны запущенный Steam, вошедший в аккаунт пользователь и обычные права процесса. Эти тесты не подменяются незаметным пропуском.

Рядом с цветными рядами вверху слева показываются пинг до другого игрока и счёт лобби. Счёт начинается с 0:0 и увеличивается у победителя, когда оба согласились на реванш и запустили следующий матч. Поле поиска карт в песочнице отображает кириллицу. Согласованный отсчёт перед боем остаётся отдельной задачей.

После ответа на предложение реванша надписи «Да» и «Нет» сразу исчезают. Карта для реванша загружается один раз, после согласия обоих игроков. Выбор карт начинается после подтверждения загрузки с обоих компьютеров. Бой начинается после выбора карт и появления персонажей на новой карте.

Для обычной игры не используйте `--rounds-p2p-smoke`: этот явный флаг включает отладочный драйвер, который выбирает карты и вызывает штатный метод сетевого урона для проверки завершения матча. В таком тестовом режиме отключена запись достижений и статистики. Без флага драйвер не включается; отключение звука возможно только отдельным параметром теста `-Mute`.
