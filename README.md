# ROUNDS P2P Mode

Мод для актуальной публичной Steam-версии ROUNDS на Windows: обычные матчи 1v1, сервер на ПК одного игрока и подключение через **Онлайн → Создать лобби → Пригласить друга**. Вводить IP и настраивать проброс портов не требуется. В версии 0.2.3 синхронизирован запуск реванша при разной скорости загрузки карты.

Приоритеты — простой запуск, качество и стабильность соединения. Сервер может работать на ПК одного из игроков. Прямое соединение предпочтительно, если оно даёт хороший результат; ретрансляция допустима, фактический маршрут нужно проверять.

Steam переносит пакеты Photon к встроенному Luxon Server. Пользователи подтвердили, что сыграли матч через Steam. Во время матча HUD показывает пинг между игроками и число побед каждого в лобби. В первом матче счёт 0:0, а победа начисляется при запуске согласованного реванша. В песочнице поле поиска карт отображает кириллицу. Отсчёт перед боем остаётся отдельной задачей.

Целевая установка — наш мод и загрузчик BepInEx в отдельном профиле r2modman, без RoundsWithFriends, UnboundLib и DuctTape. Встроенные компоненты должны поставляться с модом. Понижать версию игры для установки не предполагается.

Сборка и автоматические тесты: `./scripts/build.ps1`. Дополнительно проверить настоящий SDK Steam: `./scripts/build.ps1 -SteamTests` при запущенном Steam и обычных правах процесса. Иконка из предоставленного пользователем изображения включена в ZIP и устанавливается в кеш r2modman.

Для наблюдения за игровым тестом: `./scripts/game-smoke.ps1 -Visible`. Этот отдельный тестовый драйвер выбирает карты и вызывает штатный метод сетевого урона с большим значением; запись статистики и достижений отключена только в тестовом режиме. Стрельба этим сценарием не проверяется. Звук сохраняется; только явный `-Mute` отключает его для конкретного запуска.
