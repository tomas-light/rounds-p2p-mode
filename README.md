# ROUNDS P2P Mode 1.0.0

[Русский](#русский) · [English](#english)

## Русский

Этот мод позволяет играть 1 на 1 с меньшей сетевой задержкой (меньше ping между игроками).

### 🚀 Что добавляет мод

- Peer to peer соединение между игроками с собственным сервером.
- В игре отображается ping между вами.
- **Счёт побед.** Видно, кто сколько матчей выиграл. Победа засчитывается, когда вы оба соглашаетесь на реванш.

### 🐛 Помимо этого починили баги в самой игре

- После ответа на предложение сыграть ещё раз надписи «Да» и «Нет» больше не остаются на экране.
- При повторном матче карта больше не загружается дважды. Игра ждёт, пока она загрузится у вас обоих, и только потом даёт выбрать карты. Бой начинается, когда оба персонажа появились на карте.
- В поиске карт в песочнице теперь видны русские буквы.

### Как начать

Сделайте это оба:

1. Откройте **r2modman** — программу для установки модов. Создайте в ней новый профиль для ROUNDS. Другие моды в него не добавляйте.
2. Установите в этот профиль **BepInExPack_ROUNDS 5.4.1901**. Он нужен для запуска мода.
3. Скачайте ZIP-архив с этим модом. В настройках профиля нажмите **Import local mod** и выберите архив. У вас обоих должна быть одна версия мода.
4. Запустите Steam, затем игру через r2modman.

Когда вы оба уже в игре, один выбирает **Онлайн → Создать лобби → Пригласить друга**. Второй принимает приглашение в Steam — и можно играть.

Если окно приглашений не открывается, проверьте, включён ли оверлей Steam. Это меню Steam, которое открывается поверх игры по **Shift + Tab**.

## English

This mod lets you play 1v1 with less network delay (lower ping between players).

### 🚀 What the mod adds

- A peer-to-peer connection with a server running on one player's PC.
- See the ping between you and your friend while you play.
- **A win counter.** See how many matches each of you has won. A win counts when you both agree to a rematch.

### 🐛 We also fixed some bugs in the game

- “Yes” and “No” no longer stay on screen after you answer the rematch prompt.
- Playing again no longer loads the map twice. The game waits for both of you to load it before card picks begin. The fight starts once both characters are on the map.
- Russian letters now show up in the sandbox card search.

### How to start

Both of you need to do this:

1. Open **r2modman**, the app for installing mods. Make a new profile for ROUNDS. Don’t add other mods to it.
2. Install **BepInExPack_ROUNDS 5.4.1901** in that profile. You need it to run the mod.
3. Download this mod’s ZIP file. In the profile settings, select **Import local mod** and choose the ZIP. Make sure you both have the same mod version.
4. Start Steam, then launch the game through r2modman.

Once you’re both in the game, one of you picks **Online → Create lobby → Invite friend**. The other accepts the Steam invite, and you’re ready to play.

If the invite window won’t open, check that the Steam overlay is on. That’s the Steam menu you open over the game with **Shift + Tab**.
